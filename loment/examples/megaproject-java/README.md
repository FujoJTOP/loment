# `megaproject-java` —— 300 个 Java 语法模块、300 个函数

**用 Java 的拼法写的 Loment。** 首行 `choose write grammar java` 说的是"用 Java 的读法读这份
文件"；语义仍然是 Loment 的（`docs/188` §0：**表层语法只决定拼法与形状，不决定语义**）。

题面（用户 2026-10-11）：**用 Java 语法写 300 个函数与 300 个模块**。判据在
`tools/loment_megaproject_test.py`（与 Python 那一份同一个文件、同一个生成器约定）。

```
megaproject-java/
    README.md      这一份
    main.lomt      宿主 —— **原生 Loment**，`use` **恰好 300 条**
    j000.lomt …    300 个计算模块 —— **Java 拼法**（首行 `choose write grammar java`）
    j299.lomt
```

每个模块 **1 个函数**，整份是一个 `public class` 外壳 —— 那一层被翻译器**抹成等长空白**
（行号不漂），里面的 `public static` 方法成为顶层函数。函数名带 `j{i:03d}_` 前缀：
**发射单元的符号是平的**（ABI），跨模块同名会撞（那个报错本身也指错了东西，见 issue #221）。

## 300 这个数是**压在上限上**的

一个文件最多 `use` **300** 条（`docs/143` §93，超了报 E020）。这一份的宿主正好 300 条 ——
**没有余量**，也就是说这个项目**不可能再长大一个模块**而不分层。判据
`test_java_scale_is_300_modules_and_300_functions` 明写了这一条：

```python
assert main.count('use "j') == MAX_USE_PER_FILE, "宿主的 use 条数应当正好是上限 300"
```

要再往上就得像 Python 那一份的 `--scale` 那样搭 hub（`gen_tiered`）。

## 这一门的写法限制（都是实测撞出来的）

Java 前端（`tools/jtrans.py`，Stage A）比 Python 那一门还窄一点：

| 不收 | 实测消息 |
|---|---|
| `i++` / `i--` | `不支持自增/自减`++`` |
| `i += x` / `s += i` | `不支持 `+=`（写成 `x = x + 1;` 那种单独一条语句）` |
| 字段 / 类常量 | 全篇只用局部量（与 `java/01-intseq` 同一纪律） |
| 数组 / 字符串 / `switch` / `break` / `continue` / `~` / `>>>` | 子集外 |

所以 300 个模块里**一个类常量都没有**，循环一律写开（`k = k + 1`）。这些不是缺陷，
是这一门画出来的子集线（README 里的"不收"是设计）。

## 三方（三个数必须相等）

| | 值 | 怎么来的 |
|---|---|---|
| control（真 `javac` + `java`） | **152** | 300 份模块的**首行抹成等长空白** —— 那本来就是合法的 Java 文件；加一个 `Harness.java` 折它们 |
| loment（前门 → lomelf → WSL） | **152** | 300 份 `.lomt` 走前门翻译 → `lomentc` 检查 → LLVM IR → `lomelf` → WSL 跑 |
| expected（独立推的） | **152** | 上面那张表 + `oracle_java_total()`（闭式求和 + 比较链） |

没有 `javac` / `java` 时对照侧**可见地跳过**（打印 SKIP），不让它变成静默绿。

```
python tools/loment_megaproject_test.py
#   300 个模块、300 个函数、宿主 use 300 条（= 上限）
#   300 个模块 -> loment=152 java=152 expected=152
```

## 与 Python 那一份（`loment/examples/megaproject/`）的分工

| | `megaproject/` | **这里** |
|---|---|---|
| 语法 | Python（`def` / 模块常量） | **Java**（`class` 外壳 / `public static`） |
| 规模 | 100 模块 × 10 函数 = 1000 函数 | **300 模块 × 1 函数 = 300 函数** |
| 形状 | 平铺（宿主 `use` 100 条，有余量） | **压在上限上**（宿主 `use` 300 条） |
| 常量 | 有模块常量（避开三条缺陷形状） | **一个都没有** —— 这一门不收字段 |

两份都由同一个判据文件钉住，生成器是唯一真源。
