# 227 · 联网那一线的收口账：三层、各自的判据、以及还差什么

> 状态: **已落地**（2026-10-11）。这是一份**账**，不是新设计 —— 起点是这句话：
> "联网模块做了多少"。答案取决于"模块"指哪一层，所以本文先把三层分开，
> 每层给**能核的数**与**判据在哪**，再记这一轮收掉的两格。

## 0. 一句话

> 三层：**运行时**（两个平台的产物都能联网，`docs/217`/`docs/220`/`docs/221`）、
> **声明**（联网面是不读源码可判的数，`docs/224`）、**准入**（联网那道门，`docs/218`）。
> 这一轮：运行时**收口**（表外的号从 `-1` 改成 `-ENOSYS`，两个平台说同一句话），
> 声明层**把行为轴补上**（`excluded "network"` 不再是拦不住的声明），
> 准入层**把三件收成两件已落 + 一件待定题**。

## 1. 三层是什么，各自的判据住在哪

| 层 | 问的问题 | 今天的状态 | 判据在哪 |
|---|---|---|---|
| **运行时** | 同一份 `.lomt`，ELF 与 PE 两个产物**行为一致**吗 | 22 个号派发；四份语料两个平台**逐字节相同** | `tools/loment_pe_test.py`（16 条） |
| **声明** | "这个产物碰了哪个面"**不读源码**答得出来吗 | `surfaces`（Potato **v12**）：面名 → 站点数 + 交叉不变量 | `lomentc_test` / `potato_test` / `loment_potato_emit_test` |
| **准入** | 联网这件事**要不要证据**（宽度） | **只有文档**（`docs/218`），且它自己的结论是"激进版大概率不该做" | —— （没有判据，这一层还没有可判的东西） |

三层**不是一条流水线**：运行时不依赖声明，声明不依赖准入。分层的用处是
"问进度时知道问的是哪一问" —— 同一句"联网做完了没有"，三层的答案差得很远。

## 2. 收口：运行时的最后一处**不一致**（表外的号）

`__win_syscall` 的兜底从 **`mov rax,-1` 改成 `mov rax,PE_ENOSYS`（`-38`）**。

**为什么 `-1` 是错的**：`-1` 是 `EPERM`（"权限不够"）。用它表示"这个号我这儿没有"，
是在**说假话** —— 而 Linux 对不认得的系统调用返回的是 **`-ENOSYS`**。于是同一份源、
同一个没人实现的号，ELF 那边说"没实现"、PE 那边说"权限不够"：**两个平台对同一件事
给出两个不同的原因**，而那时的判据只比了"两边都是负的"。

**改动面**：`tools/lomelf.py` 一处（顺带加了 `mov_ri_se` —— `mov_ri32` 发的是
`mov eax, imm32`，高位**清零**，装不下负常数，这正是 `-38` 会变成 `4294967258` 的原因），
外加那条注释表（21 → 22 个号，`-1` → `-ENOSYS`）。冻出来的 blob 重冻（仍 7362 B）。

**判据**（`tools/loment_pe_test.py`）：

| 主张 | 判据 |
|---|---|
| 表外的号两个平台说同一句话 | 新语料 `enosysdemo`：`syscall4(9999,…)` / `syscall6(9998,…)` / `syscall7(9997,…)`，两边都回 `-38`，PE 与 ELF 输出逐字节相同 |
| 这条判据**不是空转** | 反证已验：把 `PE_ENOSYS` 改回 `-1`，同一份语料打出 `ENOSYS BAD a`、判据当场红 |
| 兜底那 7 个字节没漂 | `test_pe_shim_dispatches_the_documented_numbers` 解出来比对 —— **按常量比，不抄字节** |

挑 `9999/9998/9997` 而不是 `select(23)` 是有意的：那三个号**在 Linux 上也没实现**，
所以不存在"一边能做一边不能"那种**不可比**的形态。判据要的是"同一个语义两边都成立"。

## 3. 声明层：补上 `excluded` 的**行为轴**（`docs/218` §7 第 2 件）

原先那条检查（M41）比的是**名字**：`excluded "usb"` 对 `capability … : usb[…]`。
它**从不看行为** —— 所以声明了"不碰网络"、代码里却在调 `socket` 的单元，检查期一声不响。
`docs/218` §1 拿这个做了实验，结论是"门是开的"。

现在：**声明 `excluded "network"`（或 `net`）的单元里出现联网面的机调用号 ⇒ 检查期报 E005**。

* 两个实现各一份：参考 `lomentc.check`、自举 `loment/selfhost/checker.lomt`；
* 号 → 面那张表**升成了 L0 契约**：`lom/net.lom`（2026-10-11，`docs/228`）——
  编译器、链接器、自举 checker、自举 potato 四处由 `lom_audit` 的 `[net/…]` 四节 +
  `loment_net_test` 逐条对账（两个方向都查）；`loment_rule_parity` 的两条探针照旧钉行为那一面；
* **两轴照旧分开**（`docs/218` §8 最后两行）：这条只答"**门开了没有**"（权威读法），
  "外发的字节里有没有本域的数据"（保密读法，`docs/208`）是另一条 —— **谁都不替谁说话**。

判据：`lomentc_test::test_excluded_network_is_a_behaviour_claim`，
四个反向用例各自钉一件事 —— 别的空间（`usb`）不触发、别的面（`exit`）不触发、
两种写法都认、**号写成变量就什么都不说**（词法口径的诚实边界，与 `surfaces` 落 `other`
同一条）。自举侧由 `loment_rule_parity` 的 `excl-net-socket` / `excl-net-bind` 钉（两条 EQUAL）。

**顺手改正一处**：自举侧原先把"占用 excluded 空间"也发成 `E_CAP`(4)，
而参考实现同一条消息归类成 `E005`(5) —— 码集对不上，因为那一格**没有探针**所以一直没露头。
这次加了 `E_EXCL = 5` 并把两条分支都改过来。

## 4. 准入层（`docs/218`）现在的收口状态

那份激进草案的 §7 提了三件"形状与仓里既有物完全同形"的事。现在的账：

| §7 | 事项 | 现状 |
|---|---|---|
| 1 | 把 `boundary` 从"越了几次"细到"越到哪个面" | ✅ 已落 —— 就是 `surfaces`（**`docs/224`**，Potato v12）；号表与 PE 运行时判等（22 个号） |
| 2 | 声明 × 行为第一次交叉 | ✅ 已落（本文 §3） |
| 3 | `net_ladder`（照 `gc_ladder` 的形"按档拆"） | ⏸ **待定题，不是待办** —— "档"指哪一维（GC 四层？`sealed`/`hosted`？宽度？）本文从头到尾没定；第 1 件落地后"有多少联网面"已经可判，这一件多出来的只有"按档拆"那一维。**先回答按哪一维拆**，否则做出来的是第二份没人读的计数 |

而 §4 那条更硬的结论没变：**"宽度"（准入随证据变宽）本身仍然没有可判的东西**，
`lom/` 里那三个原语（`dom_admit` / `qual_feed` / `qual_seq`）一行都没动。
这一层缺的不是工作量，是**还没决定要不要做**。

**这些百分比是我按上面那三张表算的**（分子是"有判据的项"，分母是"这一层点过名的项"），
不是测出来的量；能核的数在上面每一行里。**唯一不许含糊的那一条**：
"运行时 ≈97%"里的 3% 全是**点名不做**（不是漏），而"准入 ≈5%"里的 95% 是**没决定**。

## 6. 点名不做（运行时层那 3% 的全额）

| 项 | 为什么不做 |
|---|---|
| `select`(23) | `exceptfds` 没有忠实对应（WinSock 的 except 是"带外数据 + 连接失败"）；近似的 `select` 比没有更坏 |
| `epoll` | 要 IOCP，不是一次翻译能补 |
| `sendmsg` / `recvmsg` | `iovec` 那一套；`sendto`/`recvfrom` + `syscall7` 已经够写 UDP |
| `socketpair` / `AF_UNIX` | Windows 的语义与路径规则都不同，转发会**假装成功** |
| （偏差）`poll` 只认 socket 型 fd | 文件 fd 报 `POLLNVAL`（Linux 会给 `POLLIN`）—— 写明的偏差，不是漏 |
