# 209 · 记忆的三个账户：从 Baker 1992 到率失真与量子边界

> 状态: 探索稿（2026-09-23）· **承接 `docs/207`（其 §1–§2 已被前史覆盖）与 `docs/208`（第二层）**
> · 本篇是这条线的物理侧 · **不改 L0** · 前史放在 §1，不放结尾。

## 0. 一句话

> **信息不灭。释放不是删除，是转账 —— 只有三个账户：热、内存、时间。**

## 1. 前史先行（这次放开头 —— `docs/207` 的教训）

**本文没有新机制。** 逐条点名，免得再出现一次"重发现"：

| 结论 | 谁的 |
|---|---|
| 擦除有下限 $kT\ln 2$ | **Landauer 1961** |
| 可逆计算绕开它；"重算以擦除" | **Bennett 1973** |
| **「回收 = 反向的子计算」**（"collection is reversed mutation"）、可逆语言 ψ-Lisp、连**栈**都点了 | **Baker 1992**（IWMM '92, LNCS 637, 507–524） |
| **有界内存 + 正 garbage entropy rate ⇒ 不可能无限继续**（除非 uncomputation / cleanup / compression / externalization） | **Wu 2026**（Zenodo 10.5281/zenodo.20252480） |
| 擦除的代价随**相关性**浮动（与保留集相关 ⇒ 可更便宜） | **Sagawa–Ueda** 一系（Parrondo–Horowitz–Sagawa 2015 是入口） |
| 量子信息**不能销毁，只能搬进环境** | **无隐藏定理**（Braunstein–Pati 2007） |
| 任意未知量子态**不能复制** | **无克隆**（Wootters–Zurek / Dieks 1982） |
| **uncomputation 是量子编译的标准 pass，且已有代价模型**（ancilla 复用） | **SQUARE** 一等 |
| 失真**是符号上的真度量**时率失真干净适用 | **approximate storage / approximate memory** |
| 率 = 允许的比特，失真 = 估计误差，源 = 动态系统 | **Nair–Evans** 一系（bit-rate 约束下的状态估计） |

⇒ 所以本篇的定位只有一句：**把上面这些摆进同一张账，并指出这张账在 Loment 那边能动的地方。**

## 2. 三个账户

| 信息去哪 | 热 | 内存 | 时间 |
|---|---|---|---|
| **付费**（传统回收：复用同一块） | **付**（不可再取） | 省 | 零 |
| **留着**（可逆 / 不清） | 零 | **留着** | 零 |
| **花掉**（惰性 / 重放） | 零 | 零 | **花** |

`d`（`docs/207` §3.2 那个"回卷深度"）**不是调参旋钮，它就是这条守恒律本身**：
`d = 0` 是"立刻付费"，`d → ∞` 是"全留着"。

> ⚠ **一处未核实的推测**：并行会话指出 Baker 摘要里那句 "**saves space at finer scales**"
> 暗示他**已经有粒度／窗口那个旋钮**。我没有原文，只能当**推测**。
> 若成立，则 `docs/207` 三条主张里第 1、2 条都归 Baker，只剩第 3 条。

## 3. 修正：税在**复用**上，不在**回收**上

这是并行会话给的第一条纠正，我接受，而且它改变整张账：

* `free(p)` **不擦任何东西**（写几个字节的块头）；
* 压实式收集器**拷贝活的、遗弃旧的** —— **遗弃不是擦**；
* 抹掉熵的是**下一次覆盖写**，而那次写**程序自己也要做**。

⇒ 所以这条账**分不出"有 GC"与"没 GC"**：分的是**复用**与**不复用**。
一个只 bump、从不覆盖的程序**没有任何擦除事件**，也就没有税（代价是内存无界）。

**推论**：一个程序里**唯一免税的信息，是它从未产生过的那些** —— 但这是**同义反复**，
而且它**今天没有可用的杠杆**。两条理由（2026-09-23 由并行会话指出、我逐条核过）：

1. **`gc_alpha.static_frees` 在 `main` 上不存在。** `tools/lomentc.py` 与 `tools/potato.py`
   里 `gc_alpha` / `static_frees` / `runtime_kept` 命中 **0**；`TOP_KEYS_V9 = TOP_KEYS_V8 | {"runtime"}`
   （没有 `gc_alpha`）；那两个名字**只出现在 `docs/175` §3.4.1** —— 作为**设计／判据**，
   而同一节末尾就是那份诚实账："静态那一半 ⬜ 没做"。**我把"设计里的字段"读成了"已发的字段"。**
2. **即便字段将来存在，"搬到栈上"也不免税。** 循环体里的 `alloca` 是**同一个栈槽被反复复用** ——
   上一轮的比特正是被下一轮覆盖掉的。**税一样挂在"复用"上，只是复用发生在栈上。**
   "从未物化过"这句在这里也是错的：它是**被物化**的（一块真的缓冲），只是不在堆上。

⇒ 所以这条今天**只能停在概念层**：**能记账的只有"这段内存再也没被写过"**，
而那一句对栈和堆**是一样的**。

## 4. 收集器自己的账（麦克斯韦妖）

tracing 收集器每收一次，就"学到" `H(活集)` 比特 —— 标记位、标记栈、卡表、记忆集。
**这些知识最终要被抹掉**（清标记位，或下一轮覆盖），而抹掉就是擦除。

⇒ 每个 tracing 收集器付**两张账**：垃圾的账，加**它自己知识的账**。

⚠ **但两笔账量级不同，别混（§8 分开的那条，这里也得跟着分开）：**
收集器元数据的擦除**确实存在**，可它的代价在**"工程量"那一侧** —— **比特 × 频率**，
属于刷新／带宽那一类**可测的数**，**不是 $kT\ln 2$**。把它写成热力学下限是**说反了量级**。

⇒ 于是这条的正确形态是**工程结论**，不是热力学结论：

> **收集器的状态越小，它每轮要抹的元数据越少** —— 标记位／卡表的**带宽与刷新代价**随之下降。
> 若某条收集路径的状态能缩到只剩 PC，那部分代价就是零（PC 是**本来就在**的寄存器）。

> ⚠ **"最小状态 = 最小熵"这半句我撤**：它把工程账说成了热力学账。
> 留下的是它的工程形态，以及那条**可量**的说法：**标记位比特数 × 收集频率**。

## 5. 汇率不是常数（广义 Landauer）

若被擦的比特与"你保留的东西"**相关**（有互信息），擦它的代价**低于** $kT\ln 2$，
极端情形为零。翻译成内存管理：

> **"哪些字节是派生/冗余的"有一个物理量：与保留集的互信息。**
> 该丢的是互信息**高**的；该留的是互信息**低**的（不可再生）。

精度上一句：**"确定性可重算"是它的端点**（条件熵 $H(X\mid Y)=0$）。
缓存、索引、反规范化副本因此是**手续费最低**的那一类 —— 这不是工程直觉，是汇率。

## 6. **"允许错"才是率失真的入口**（本篇的主结果，来自并行会话的纠正）

`docs/208` §6 最初把它写成"观察集 = 失真度量 ⇒ 回收 = `R(0)`"。**这个类比只在半路上成立**：

* `R(0)` 只是"**商集的熵**" —— 一个**单点**，不是曲线。它给"不可约信息"一个标准名字，
  **但不带来任何定理**：`D = 0` 意味着"答案不许错"，率失真那套**权衡**结构整个塌掉，
  剩下的话与 **Wu 2026 / Baker 1992** 说的是同一件事。
* **率失真真正的内容在 `D > 0`** —— 而那意味着**允许算错**。

所以这条类比要成立，语言得先有一样东西：**声明的误差预算**。于是：

| 声明什么 | 得到什么 | 有定理吗 |
|---|---|---|
| **我能观察到什么** | `R(0)` 这个地板（= 不可约信息） | **没有新定理**（Wu 2026 的范围） |
| **我能错多少** | `D > 0` 的权衡曲线；可算上界这时才成立 | **有** —— 率失真的正典在这里 |

**而两处声明在同一张面上。** 语言里已经有一类"声明过的精度"：

```rust
let x: u32 = ...;
let y: u16 = x as u16;   // 窄化 —— 一次**声明过的**精度损失（丢掉高位）
```

> ✅ **判据在，但它量的是另一件事（2026-09-23 核过）。** `E017`「`as` 转换非法」
> （`tools/loment_diag.py:103`）判的是 `as` 的**类型合法性** ——
> "`as` **只能**整数⇄整数/布尔，目标必须是基类型；其它转换要显式构造"；
> 而 `loment_diag.py:503` 那句明写 "`as` 只做**位级**的转换：整数⇄整数、整数⇄布尔、指针⇄整数"。
> **所以它在、它管 `as`，但它不判丢位。** ⇒ "窄化是语言里已经声明过的精度"这句只能写到：
> **语法上声明了要窄化，但编译器不保证你看得见丢的是什么** ——
> **`E017` 就是那个"近乎命中"的判据**，这比"没有判据"更准，也更难被人挑。

### 6.1 前史先行：误差预算本身不新，可能新的只有半步

* **声明精度**早有一大族：Ada 定点、DSP 语言、Verilog、**approximate-computing 的 DSL**
  （把误差界放进类型的那一类）、以及 **"Numerical Fuzz: A Type System for Rounding Error
  Analysis"**（arXiv:2405.04612）这种舍入误差的类型系统。
* **失真在符号上是真度量**时率失真干净适用：approximate storage / approximate memory。
* ⇒ **可能新的只有半步**：不是"按有界精度**算**"，而是"**回收受误差预算许可**"——
  状态**可以因为申报的误差而被丢掉**。主张更小、更尖，也更容易证伪。
* **它属于运行时/宿主侧，不属于核。** "核永远说一不二"是核少有的几条必须守住的东西之一，
  而 `choose runtime` 那一维（`docs/175` §3.6）正好是它的家。
* **第一件产物该是判据，不是关键字**：给定程序 + 申报预算，量 `(峰值内存, 输出误差)`，
  检查预算守住 —— **不碰冻结面**（不加关键字、不动 L0），却是最便宜的一次"有没有内容"的判断。

前史就在隔壁：**approximate storage / approximate memory**（失真在那里是符号上的真度量）、
**bit-rate 约束下的状态估计**（Nair–Evans：率 = 比特，失真 = 估计误差，源 = 动态系统）。

## 7. 量子：两条定理，一正一反

**(正) 释放不是删除 —— 两侧都不是设计选择。**

* 经典侧：**Landauer** —— 擦 = 信息进环境 = 热。
* 量子侧：**无隐藏定理** —— 信息**不能**藏在系统-环境的**关联**里，必须**完全**落在环境态中。

⇒ 对量子信息，"删除"更不是一个可用操作，**搬移是唯一形态**。
Baker 的可逆性因此不是"一种做法"，是**两侧定理都指向的那个形态**。

**(反) 重放只对可克隆的信息成立 —— 这条给 `docs/207` 的重放回收划界。**

**无克隆** ⇒ 任意未知量子态不能复制 ⇒ **不能重算**。
而"**可复制且不被扰动**"正是**经典性**的定义之一。于是：

> **重放回收的适用域 = 经典信息。** 它对量子内存**不成立**。

**顺带一条前史**：uncomputation 在**量子编译**里是**标准 pass**，而且**已经有代价模型**
（ancilla 复用的那类工作）。也就是说，"用反算换宽度"在那边已经是**工程**，不是研究课题。

## 8. 物理基底自己也在收集

DRAM 每 **64 ms** 刷新；闪存有电荷泄漏；量子内存有 $T_2$ 退相干 —— **物理基底会自己腐烂**。

⇒ **"必须回收"这件事，一半的原因在程序，另一半在基底。** 极端地说：**刷新就是物理层的 GC。**

⚠ 而且要诚实：**真实世界那笔能耗的正主是刷新功率，不是 $kT\ln 2$** —— 两者差**几个数量级**。
拿 Landauer 当省电理由，就是把两个量级的东西混着说。

## 9. 终极上限（框架，不是今天能用的东西）

**Bekenstein / 全息界**：一个区域能容纳的信息有**面积**上界。
所以"最小信息"这个目标函数有一个绝对终点 —— 离今天任何内存还有**几十个数量级**。
这一层只能是框架，写在这里是为了说明这条轴**有终点**。

## 10. 没证的（清单，别当成已经解决了）

* **税在复用上**这条（§3）我接受并行会话的论证，但**没有自己验过**
  （要验就该量"复用次数"，不是"回收次数"）。
* **`static_frees` 那一条**（§3）**已被撤回** —— 它在 `main` 上不存在（只活在 `docs/175` §3.4.1
  的设计里），而且"搬到栈上"不免税。**这条不要再引**。
* **收集器自身的熵账**（§4）**没有找到先行工作** —— 但也没有找到反例。
* **广义 Landauer → 该丢互信息高的**（§5）**没有实测**，也没有把互信息接到编译期的办法。
* **§6 那张表**里"我能错多少"这一半，**在 Loment 里没有任何实现**；
  连"窄化有没有编译期判据"我都只查了 `lomentc.py` 的一处 grep，**不算查过**。
* **无克隆 ⇒ 重放只对经典数据成立**（§7）是真的，但它在**混合态/容错量子计算**里
  的精确形态（经典数据在量子基底上可复制到什么程度）**我没查**。
* **Baker "finer scales"**（§2）是**推测**。
* **§9 全息界**与内存管理的接口**没有** —— 它是框架，不是主张。

## 11. 收口：Loment 这边能动的是什么（三条，都不需要新物理）

1. **"从未物化"是唯一免税的信息**（§3）—— 但它是**同义反复**，而且**今天没有可用的杠杆**：
   编译器要真的**消除**（寄存器化／融合）才算，**搬到栈上不算**（栈槽照样复用、照样擦）。
   `static_frees` 是 `docs/175` §3.4.1 的**设计字段**，`main` 上还没有 —— 所以这条是**方向**，不是字段。
2. **最小状态收集器**（§4）—— 状态越小，自我负债越少。`docs/207` 那条"状态只有 PC"
   因此不是优雅，是**账面为零**。
3. **丢互信息高的**（§5）—— 缓存 / 索引 / 派生副本。

**而"允许错"那一条（§6）今天还不能动** —— 因为语言里没有**声明的误差预算**。
它是这篇文章指向的**下一个新词**，不是今天能写进 `choose` 的东西。

**最后一句**：这三条**没有一条需要新物理**。物理在这里的作用不是给出新机制，
是**划出哪几笔账根本不用还** —— 而那几条恰好都可以今天就做。
