# 208 · 第二层攻得下来：可观察语义垃圾 = **声明上的不可观察**

> 状态: 探索稿（2026-09-23）· 承接 `docs/207`（**其 §1–§2 已被前史覆盖，见该文顶部的撤回块**）
> · **本文只主张一件可判定的事**，其余全是它的边界与缺口 · 不改 L0。

## 0. 一句话

> **判据不是能力的「存在」，是能力的「不可达」。**

## 1. 为什么第二层在这门语言里攻得下来

传统 GC 的判据阶梯（`docs/207` §1）第 2 层是"**语义上未被观察**"，
一般不可判定 —— 因为它量化的是**程序的未来行为**（"以后还会不会读它"）。

但 Loment 有一件别的语言没有的东西：**"能观察到什么"是声明的，不是推断的。**

| 声明装置 | 它说什么 | 判据 |
|---|---|---|
| `capability N : space[lo..hi]` | 这个单元**能观察**哪些外部状态 | 能力表（编译期） |
| `excluded "space: ..."` | 这个单元**不申请**某空间（负向） | **M41 / E004**（`docs/146`、`docs/145`、`docs/150` 的"第一遍半"） |
| **Potato** | 把上面的声明记进产物 | **不读源码可判** |

于是命题可以收紧成一句**可判定**的话（这就是 peer 那份转达里的主命题）：

> **不可观察集 = 声明上不可观察的集。**
> 不必判"有没有被观察"，只判"**在不在一个声明为不可观察的域里**"。

这比"可达"强（它是语义的、不是指针的），比"语义未观察"**可判**（它不量化未来，只读声明），
**而判据是现成的**（M41）。

## 2. 精确形式（比"声明上不可观察"还要紧一格）

令 `Obs(u)` = 单元 `u` 声明覆盖的空间 \ `excluded` 声明的空间。
`Obs(u)` 是**局部**的、静态的、M41 已强制的。

但回收判据需要的不是它，是**闭包**：

```
Obs*(u)  ≔  Obs(u) 沿「u 能调到谁」取传递闭包
x 可回收  ⟺  ∀u : x ∉ Obs*(u)
```

**关键差别**：

> **M41 保证的是 `Obs(u)` 局部自洽，不保证 `Obs*(u) = Obs(u)`。**

`excluded "net"` 说的是"本单元不申请网络能力"——**它不说"本单元到不了网络"**。
只要 `u` 能调到一个有网络能力的 `w`，`u` 就能**间接**观察网络。
`Obs*(u)` 里就多出了 `Obs(u)` 里没有的东西。

## 3. 缺口：传递（**这是全文的关键**）

缺口就在上面那一条。两条出路，一条能落、一条是真话但窄：

### 3.1 `closed "space"` —— 把 `excluded` 从「我不申请」升级成「我到不了」

`closed "S"` 的语义应当是：

> **本单元及其可达闭包里，不存在通往 `S` 的能力。**

它的判据面从**能力表**扩到**调用图闭包**，与 M41 **同族**（`docs/146` 那张表加一行的事），
形状大概是：

```
单元 u 声明 closed "net"
  ⇒ 对 u 可达闭包里的每个 w：w 的能力表 ∩ net 空间 = ∅
  ⇒ 否则编译错误（M41 的传递版）
```

代价：`closed` 比 `excluded` **强**，所以它**更难声明** —— 它把一个单元和它调用的一切绑在一起。
一个库改了依赖，可能让上游的 `closed` 失效。这是它的价格，不是它的缺陷。

### 3.2 或者：**只对叶子单元成立**（今天就能立）

叶子单元（不调用别的单元）没有传递问题 —— `Obs*(u) = Obs(u)`，判据就是 M41。

**这是真话，而且今天就可判。** 覆盖面窄，但它不需要任何新关键字、新判据。
写在这里当作"这一层今天能落地到哪儿"的答案。

## 4. 这一族的门：**静态可调用图**

上面两条路（以及 `docs/207` §11 提到的"静态 frontier 表"）都要**同一个语言性质**：

> **`u` 能调到谁，是编译期可知的。**

于是它从"某个方案的前提"升级成**这一族方案的门**。在 Loment 里，这个门的具体问法是：

* 动态分派（trait 的多态调用）算不算"能调到谁"的边？
* 函数指针 / 间接跳转呢？
* `choose` 已经有一维 `runtime`；这里要的是一个**图的形状**，不是开关。

**这道门比 `closed` 本身重要**：`closed` 只是个声明，门是"这张图存不存在"。
如果图是静态的，`closed` 就是 M41 的一次推广；如果不是，这一整族东西都只能退到叶子单元那一档。

## 5. 它证不到哪儿（诚实边界，别当成已经解决了）

1. **间接可达**（§3 那个缺口）—— 非叶子单元上，`excluded` 不足以支撑判据。
2. **动态分派 / 间接跳转** —— 会让"可达闭包"从静态表变成不可知（§4 那道门）。
3. **`excluded` 的语义今天不是这个** —— 今天它是"**不申请**"，不是"**到不了**"。
   把它读成后者是**误读**，本文的全部主张都建立在"要给它加一个传递版本"之上。
4. **即便 `Obs*` 全部成立，它给的是上界，不是精确值**（§6）——
   它是"**最多**能观察到这些"，不是"**恰好**观察到这些"。
5. **`guard` 不是这条链的一部分。** `guard CAP(e)` 是**审计点**（`@__loment_audit`，`docs/147` A2），
   它记的是"发生过一次域检查"，**不是**"这个单元能观察什么"。别把两者混起来。

## 6. 与物理目标的关系（预告 `docs/209`）—— 以及这条类比**在哪儿断**

我最初把它写成"观察集 = 率失真理论里的失真度量，回收 = `R(0)`"。
**一条来自并行会话的纠正说明这个类比只在半路上成立**，记在这里，因为它改变了 `docs/209` 的脊。

**对的那半**：

* 把**合法观察集**当作信息论里那个**失真度量**（观察不到的区别 = 零失真），
  回收就是**零失真约束下的率最小化**：`R(0)`；
* 拿**恒等**失真（每个比特都能被观察）⇒ `R(0) = H(X)`，一个比特都压不掉；
  拿**声明的观察集** ⇒ 失真度量变粗 ⇒ 地板降低；
* 而"最短描述"版本就是 **Kolmogorov 复杂度** ⇒ 一般**不可判定**。
  ⇒ **第 2 层那堵墙与物理那堵墙是同一堵墙。**

**断掉的那半（这条才是要紧的）**：

> **`R(0)` 只是"商集的熵"** —— 一个**单点**，不是曲线。它给"不可约信息"一个标准名字，
> **但没有带来任何定理**：`D = 0` 意味着"答案不许错"，率失真那套**权衡**结构整个塌掉，
> 剩下的话与 Baker 1992 / Wu 2026 说的是同一件事。

**率失真真正的内容在 `D > 0`** —— 而 `D > 0` 在这门语言里意味着**允许算错**。
所以这条类比要成立，语言得先有一样东西：**声明的误差预算。**

好的那面是：这个"声明"与本文 §2 的"声明"**是同一套装置**
（`capability` / `excluded` / `closed` 那一片就是声明面）：

| 声明什么 | 得到什么 | 有定理吗 |
|---|---|---|
| **我能观察到什么** | `R(0)` 这个地板（= 不可约信息） | **没有新定理**（就是 Wu 2026 的范围） |
| **我能错多少** | `D > 0` 的权衡曲线；`Obs*` 这时才真是可算上界 | **有** —— 率失真的正典在这里 |

> **两条轴不是"缝在率失真上"，是缝在同一张声明面上** —— 而只有后一半有定理兜底。

`docs/209` §6 展开后一半。它的前史是 **approximate storage / approximate memory**
（那里失真**是符号上的真度量**）与 **bit-rate 约束下的状态估计**
（Nair–Evans 那一系：率 = 允许的比特，失真 = 估计误差，源 = 一个动态系统）。

### 6.1 它与 Wu 2026 是**不是**同一个量（2026-09-23 读了原文）

并行会话提出：既然给定的输入下程序是确定的，那个熵就是输入的熵，那它就是 Wu 2026 在算的账 ——
**那么这半节该写成引理、引 Wu，而不是当自己的结果。** 我把 Wu 的原文抓下来抽了文本，结论是：

> **不是同一个量。** 而按那条规矩 ——**差值本身就是结果。**

Wu 的 **Definition 4**：`r_G = lim inf t⁻¹ H(G_{1:t} | R_t)` —— 一个**率**（每步比特），
算在**垃圾记录过程** `G` 上，且**以保留下来的记录 `R_t` 为条件**。
它另有一个**存量**类的量（"garbage load" `H(G_{1:t} | R_t)`，比特）。
**关键是：这两个都活在"该还的那一侧"** —— 要搬走、要清掉的逆信息。

而本节那个 `R(0)` 活在**"还不掉的那一侧"**：不可约的观察信息。

| | 量纲 | 算在什么上 | 管哪个资源 |
|---|---|---|---|
| Wu：`r_G` / garbage load | 比特 **/ 步** 、 比特 | **垃圾记录过程**（逆信息） | **排**得多快（dissipation 吞吐） |
| 本节：`R(0)` | 比特 | **可观察投影**（输入经确定性映来） | **留**多少（footprint 地板） |

**两根相互独立的轴**，一对反例就够：

* **大存量、零流量**：把一张大表从大输入物化出来，之后**只读不写**。
  存量 = `H(输入)`（若全可观察），流量 ≈ 0（没有非单射更新 ⇒ 没有逆信息要留）。
* **小存量、大流量**：可观察状态只有一比特，但内层反复做非单射运算（为保可逆而保留输入）。
  存量极小，流量大。

⇒ **不相等。而差值就是结论**：**Wu 的定理约束"排"（有界内存 ⇒ 必须清），
本节约束"留"（观察集 ⇒ 地板）。两者不能互相代入** —— 一个程序可以满足一头、违反另一头。

⇒ 因此 §6 上面那半**要按标准引理写**（`R(0)` = 商集的熵，信息论的常规事实），
**把 Wu 的模型引作它的语境**，而**不是**当成本文的结果。本文能主张的只剩一处：
**把「程序声明的合法观察」当作那个失真度量** —— 那才是这一节唯一可能新的半步（仍**未证实**）。

## 7. 两条最小反例（"不要生命周期，能不能拿单射"）

本文的动机之一是 `docs/207` §5 那个研究问题。两条路各给一个最小反例，
都能从本仓**已写下的记录**推出来：

**路 (i)：在受约束子集里要求唯一引用 —— 拿不到单射。** 反例直接来自 `docs/206` §2.1
（E007 只在"**同一次调用之内**"查）：

```rust
let a = &mut p;   // 同一次调用内查过 —— 通过
let b = &mut p;   // 换一条语句，不再查 —— 也通过（docs/206 §2.1）
*a = 1; *b = 2;   // 写不是单射：*a 的旧值取不回来 ⇒ 反算不成立
```

⇒ **没有生命周期，就没有"唯一引用"；没有唯一引用，写就不是单射。** 这就是答案。

**路 (ii)："不可反算处退回收税" —— 在从不复用的程序上等于零内容。** 反例：单调 bump、
从不覆盖的程序。那里**没有擦除事件**，也就**没有税可省**（`docs/209` §3）——
方案退化成"什么都不做"。⇒ (ii) 不是通往单射的路，是**逃生阀**，
且它的适用面恰好落在"本来就不需要回收"的那类程序上。

## 8. 与 `docs/205` P6 的边界（能划清）

`docs/205` 的 P6 行把"**语言级惰性**"列在**明确不抄**，理由是要么分配、要么把状态机写进类型。
本文（及其物理侧）要的是"**物化可以退化成重放**"——**哪个物理副本留着**，是**回收语义**，
不是**求值语义**（值什么时候算）。

不撞的判据只有一条，而且很干净：

> **重放对程序不可观察**（结果不变；代价只落在时间上）。

一旦重放会改变可观察行为（失败 / 顺序 / 副作用），它就变成求值语义 ⇒ **撞 P6**。
**而这条判据与 `docs/207` §10 的度量 3（正跑 → 反跑 → 逐位比对）是同一条** ——

> **安全义务和不撞 P6 的义务，在这里重合了。**

## 9. 判据（可做，**尚未测**）

| 要量什么 | 怎么量 | 它决定 |
|---|---|---|
| **叶子单元占比** | 每个单元是否引用别的单元的外部符号 | §3.2 那一档今天能覆盖多少语料 |
| **声明了能力且调用了别的单元的单元数** | 上面 ∩ 有 `capability` 声明 | §3 那个缺口咬到多少地方 |
| **可调用图的静态度** | 调用点里动态分派 / 间接跳转的占比 | §4 那道门开不开 |

三个数都**没有测**。第一个最便宜（词法就能给上界），第三个最难也最关键。
