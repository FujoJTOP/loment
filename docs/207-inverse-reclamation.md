# 207 · 回收是程序的逆运算：一个不是 GC 的东西，以及它的三个新名词

> **状态: 探索稿（2026-09-23）。** 无实现、无测量、无判据进门禁。**不改 L0。**
> 与在飞的 **PR #105**（`choose` 加 GC 三档 + 运行期维，`feat/gc-v8`）**同域、互补**：
> 那条线在定**形态与档位**，本文写的是那个槽的**本体论**。前史见 §13。

## 0. 一句话

**传统内存管理把"释放"当成擦除。本文把"释放"换成程序的逆运算。**
于是收集器不再是程序外面的一个子系统 —— **它是程序的一半**。

它与 GC 的关系可以只用一句说：

> **传统收集器是本文那个标量的退化点（`d = 0`）。** 不是"又一种 GC"，是收集器所在的那条轴。

## 1. 四个层次的判据，与一条物理下限

内存回收的判据是层层收紧的，每一层都比上一层难：

| 层 | 判据 | 它撞上的墙 |
|---|---|---|
| 1 | **可达**（传统 tracing） | 无 —— 但它只是近似 |
| 2 | **语义上未被观察** | **不可判定**（语义垃圾一般不可判别） |
| 3 | **可重算**（重放回收） | 可判定，但重算有代价 |
| 4 | **可逆**（本文） | 物理：见下 |

第 4 层的墙是**物理**的，不是知识的：

**Landauer（1961）：擦掉一个比特，至少耗散 $kT\ln 2$。**

而**回收按定义就是擦除** —— 活跃集相同的所有状态被坍缩成一个，这是一个多对一映射，
**必然抹掉熵**。于是任何收集器都有一条下限：

$$
E_{\text{reclaim}} \;\ge\; kT\ln 2 \times \Delta H
$$

$\Delta H$ 是被抹掉的逻辑熵。这不是"现在的收集器效率低"，是热力学给收集器判的刑：

> **零能耗 GC 不可能 —— 因为"释放"这个词的物理内容就是"擦"。**
> 第 1/2/3 层都在交这笔税，只是没算过它。

## 2. 唯一的逃逸：反算

**Bennett（1973）：要不产生需要擦的信息，唯一的办法是把计算倒着跑回去。**
可逆计算的纲领就一句：**能耗只来自逻辑上不可逆的操作。**

于是本文的立论：

> **回收 = 程序的逆运算。**

这句话把第 2、3 层收编成定理，而不是并列的三种想法：第 3 层的"重算以擦除"
（Bennett 那个手段）、第 4 层的"不擦"（Bennett 的结论）是**同一个定理的两端**。
中间那个旋钮就是 §3.2 的 `d`。

## 3. 三个新名词

本文不发明确一种新 GC。**本文给一个还没有名字的东西命名**，三个。

### 3.1 `unfree` —— 与 `free` 互逆的那个原语

`free` 擦除；`unfree` 反算。两者是同一个事件在两个方向上的名字。

```rust
// 今天：free 的语义在 origin/main 上还是占位（docs/175:146 引 SKILL.md「占位（bump 堆不真回收）」）
//       在 PR #105 里它被兑现成"bump + 地址序空闲链表 + 拆分 + 前沿回退"
free(buf);

// 本文：free 的对偶
unfree(buf);   // 不是"把它还回去"，是"把它倒回去"
```

**注意与 PR #105 的对齐与差异**：那条线实现的 `free` 里已经有**前沿回退**——
正是本文 `unfree` 的机械骨架。差异在簿记：它有地址序空闲链表（因为要支持**拆分**与
**任意块归还**）；本文说，若接受"回收即反算"，`free` 可以**只剩前沿回退**，一个链表都不用。
**这是本文唯一敢说"比已有实现更轻"的地方，也是最容易被证伪的地方。**

### 3.2 回卷深度 `d` —— 一个标量，三个刻度

| 回卷深度 `d` | 内存 | 时间 | 能耗 |
|---|---|---|---|
| **`d = 0`** | 立刻回收，最省 | 零 | **付满 Landauer** |
| **`d` = 一个窗口** | 保留 `d` 个世代 | 反算 `d` 步 | 只付**穿越窗口的不可逆比特** |
| **`d → ∞`** | 历史必须全驻留 | 可任意长 | **零**（完全可逆，Bennett） |

**一个旋钮，同时调内存、时间、能量；两个端点各有定理兜底。** 传统收集器只是左端。

### 3.3 熵界 —— 能力域的热力学身份

本文唯一真正新的断言（§6）：

> **能力域不只是安全边界，它是热力学边界。**

## 4. 不可逆性在语言里从哪来

只有三个来源，第三个是本文的落点。

1. **非单射原语**（`and` / `or` / 除法 / 截断）：每次操作抹掉比特。
2. **别名**：**头号杀手。**`*p = v` 毁掉旧值，还毁掉"别的指针也看见过它"这个事实。
3. **I/O 与环境**：读一个时钟、一个传感器，**绝对不可逆** —— 你没法"没读过"。

## 5. 这条线在仓里已经画到哪儿了（本节是本文的诚实面）

第 2 条要的是**唯一引用**（没有别名 ⇒ 写是单射 ⇒ 可恢复旧值）。**Loment 今天没有这个性质，
而且这是一条写下来的决定**：

* `docs/206`（2026-09-23）：所有权只证**三条** —— E007 可变别名（**同一次调用之内**）、
  E006 移动后使用、E012 悬垂借用；**不证四条** —— 不看生命周期、不跨函数、
  无字段级移动、移动集不分分支。每条都指到 `lomentc.py` 的 `_check_borrows` / `_move_check`。
* `docs/205` R1 行：**Rust 的 NLL 级借用检查在"明确不抄"里**（§3 那张表）；
  走的是"**能力域 + 移动/借用子集**"。

于是有一条**正面相撞**：本文 §2 要唯一引用，而唯一引用的完整形式已经被明确拒了。

**但 `docs/206` §0 自己给了出路**：R1 的裁决是"**换形式抄** —— 要那个目的
（**编译期就能回答'这段碰得到什么'**），不要那个形式（NLL 级的引用图）"。
**本文 §2 要的正是那个目的。** 所以这不是"再抄一遍 Rust"，而是给那个目的**加一个新的消费者**：
那个答案为 PR #105 的根表 / 布局描述符服务（它已经把 `docs/206` 那张表用起来了），
**本文要它顺带服务的第二件事是可逆性。**

待验的问题（这才是研究问题，不是结论）：

> **能不能不要生命周期、只要"这段碰得到什么"的答案，就拿到单射性？**

两条可能的路，**都不需要 NLL**：(i) 只在**受约束的子集**里要求唯一引用
（与 PR #105 对 `gc_auto_alpha` 的处置同一种思路：按子集开）；(ii) 接受"不可反算处退回收
Landauer 税"（§8 第 1 条）。

## 6. `excluded` 是一份热力学声明

`excluded "net"` 的现行语义是**负向封闭**：本单元不申请该能力（`docs/142`），
且**能力空间命中 `excluded` 声明的空间即编译错误**（M41 / E004，`docs/146` 那张表；
`docs/145` M41；`docs/150` 的"第一遍半"）。

把它翻译成物理语言：

> **不可逆前沿的位置，就是 `excluded` 声明的位置。**
> 域内不跨世界 ⇒ 域内没有不可逆的环境读 ⇒ **域内可反算**。

关键在**它有判据**：封闭性不是承诺，是 `M41` 已在编译期强制的事实。于是核心命题可写成一行：

$$
E_{\text{reclaim}} \;\ge\; kT\ln 2 \times (\text{跨能力域边界的比特数})
$$

**域内为 0。** 没有现存语言把 capability 当热力学概念用过 —— 这是本文赌的那个数量级。

> ⚠ **但 M41 保证的比本文要的窄**：它保证"域**不占用** `excluded` 的空间"，
> **不是**"域内不存在任何通往世界的路径"（例如间接、经另一单元）。
> 这个缺口本文当作**待验假设**看待，不当作已成立（§12）。

## 7. 极限形态，以及白送的一样东西

堆的大小变成**时间的函数**；"释放"与"反算"变成**同一个事件**；GC 作为一个子系统**消失**，
剩下的是**时间可逆的执行**。

白送的收获：**没有擦除事件，就没有可观察痕迹。** 可逆收集器**天生对侧信道免疫** ——
传统收集器的时序本身就是一条信息泄漏通道。**这一条不在 PR #105 的三条主张里，
也不是它的推论** —— 它是本文独有的一格。

## 8. 诚实的断点（三条）

1. **非单射原语满地都是** → 只能靠 Bennett 的"历史位"，而历史**又是内存** ——
   **问题被搬走了，不是被解决了。** 唯一活路是"有界历史 + 重算"。
2. **I/O 绝对不可逆** → 只能可逆到前沿为止（§6 指出前沿在哪，同时指出那里的缺口）。
3. **最扎心的一条**：$kT\ln 2 \approx 2.8\ \text{zJ}$ @ 300 K，而现代 CMOS 离这个极限
   还有 **3–5 个数量级**。**今天为省电做这件事，省下来的约等于零。**

## 9. 与"语言级惰性明确不抄"的区别（必须辨明）

`docs/205` P6 行把"生成器 / 迭代器协议 —— **语言级惰性**"列在**明确不抄**，
理由之一是"要么分配（撞无运行时）、要么把状态机写进类型（撞 R1 的边界）"。

**P6 拒的是"语言级的惰性求值"** —— 值**什么时候算**，这是**求值语义**。
**本文要的不是那个**：本文要的是"**物化可以退化成重放**" —— 哪一个**物理副本**留着，
这是**回收语义**。

但两者**共享同一份代价表**（都要"可重算"）。所以 P6 的理由适用于本文的**强版本**
（把重放接进取值），**不适用于弱版本**（只在回收策略上动）。**这条边界本文没查清**，
写在这里待验（§12）。

## 10. 判据（**尚未测量** —— 本节是"该怎么量"）

三个数。**目前一个都没有**；写下算法，是为了让下一个人能把它变成真判据。

1. **能免 Landauer 税的比例** = corpus 里 `capability` / `guard` 覆盖的比特数 ÷ 总比特数。
   数法：按能力声明与 `guard` 点，对每个单元统计其可及内存；分母是全单元总内存。
2. **非单射原语密度** —— 决定历史位开销。数法：`and` / `or` / 除法 / 截断 / 窄化的
   **站点数 ÷ 总操作数**。
3. **正跑 → 反跑 → 逐位比对** —— 唯一能在 CI 里验证"**逆是精确的**"的办法。
   **这是安全面的全部**：逆不精确 → 不反算 → 退回普通回收（付满 Landauer），永远不出错。
   （形状与 PR #105 那条 `gc_manual` 的**证伪对**同一个思路：要有一只程序**必须**红。）

**读法**：数 1 低、数 2 高 → 本文是诗。两个数都合适 → 才是纲领。

## 13. 前史与窄新颖面

**前史（不绕开）**：可逆计算（Landauer 1961；Bennett 1973，含"重算以擦除"那个手段；
Fredkin / Toffoli 门；Frank 一系）是地基。**可逆语言的实现工作里，GC 一直被当成麻烦**
（回收要小心别毁掉反算所需的历史）。区域推断 / 线性类型在"静态内存上界"上早有建树。
能力域与撤销有成熟系统（CHERI / Cornucopia 一族）。本仓**已有**的那条 GC 线上，
"根由编译器发出"（PR #105 §3.4.1）与本文"没有根"是同族但不同的主张。

**本文主张的只有三条**：

1. **把关系倒过来** —— GC 不是可逆语言的麻烦，**GC 就是可逆语言的产物**：回收即反算。
2. **回卷深度 `d`** 作为**统一内存 / 时间 / 能量**的单一标量，两端由 Landauer 与 Bennett 夹住；
   **传统 GC 是它的退化点**。
3. **能力域 = 热力学边界**，且这个边界在本仓**已有判据**（M41）而不是口号。

**收口**：那个 0.000000001% 不是"赌它会成"。它是一条**可拿掉的假设** ——
不可能性论证（"回收就是擦除，所以必然耗散"）里那个"**必须擦**"。
拿掉之后，剩下的每一步都是定理：Bennett 的、Landauer 的、以及 `M41` 的。
