# 206 · 所有权与借用的边界：哪些能证、哪些不证

> 状态: 边界说明（2026-09-23）· 落点: `docs/manual`（本文收进 `loment_manual.SPECS`，
> 出现在手册的「规范」一栏里）· 输入: `docs/204` §2 的 R1、`docs/205` §1.2 的 R1 行
>
> 一句话: R1 的裁决是**换形式抄** —— 要那个目的（编译期就能回答"这段碰得到什么"），
> 不要那个形式（NLL 级的引用图）。既然要，就必须把**证到哪儿为止**写下来。
> 这一页就是那条线。

## 0. 为什么这条线必须写下来

Rust 的卖点是借用检查，代价是把生命周期写进类型。我们不要那个代价，
所以问题不再是"抄不抄"，而是"**我们替读者证到哪儿为止**"。
这个问题有个特点: **不写下来，答案就只存在于实现里** —— 读者只能靠试。
试出来的边界不是边界，是运气。

`docs/205` §1.2 的 R1 行把这一条记成 `已有（+ 文档）`: 检查器在，缺的是那句话。

## 1. 证的：三条，各一个诊断码

三条都在 `tools/lomentc.py` 里，函数名比行号稳（行号会随重构漂，函数名不会）。

| 码 | 拒的是什么 | 由哪个函数拒 |
|---|---|---|
| **E007** | 同一次调用的实参里，同一个变量既被 `&mut` 借又被 `&` 借；或者被 `&mut` 借**两次** | `_check_borrows` |
| **E006** | **非 Copy** 类型的变量被移出之后又被用、或被赋值 | `_move_check` |
| **E012** | `return &local` / `return &mut local`，而 `local` **不是参数** —— 返回了一个悬垂借用 | `_move_check`（`Return` 那一路） |

**Copy 的分界线**（`_is_copy_type`）：标量、枚举、切片、`str` 是 Copy；
`struct` 与数组**不是**。所以"移走一个 struct 再用"会被拒，而"移走一个 `u32` 再用"不会
—— 后者本来就没有东西可移。

**什么时候算"移出"**：按值把一个非 Copy 变量传给函数，或 `let x = y`（`y` 非 Copy）。
切片参数是例外，它是借用，不算移。

## 2. 不证的：四条

这一节是这一页真正的价值 —— 上面那三条容易读成"Loment 有借用检查器"，
而下面这四条说明它**不是**什么。

1. **借用不看生命周期，只看"同一次调用之内"。**
   `_check_borrows` 只在**调用点**被调，收到的是那一次调用的实参表。
   跨语句并存的两个借用、活到调用之后的引用 —— 只要不是 E012 那个形状，编译期不管。
2. **不跨函数。** 所有权不进函数签名: 被调函数内部怎么用它的参数，调用方查不到;
   反过来也一样。所以"这个函数会不会吃掉我传进去的变量"在 v0 里**不是一个可问的问题**。
3. **没有字段级（部分）移动。** 记账的单位是**变量名**: `moved` 里放的是 `p`，
   `p.a` 只被当作"读了 `p`"。移走 `p.a` 与移走 `p` 不是两件事。
4. **移动集不分分支。** `moved` 是整条函数体共用的一份（分支体的作用域是复制的，
   移动集不是）。于是 `if` 的某一支里移动了，另一支也按"已移动"算。
   **它偏保守，而且这是实现的事实，不是设计承诺。**

## 3. 证不了的时候发生什么

线以内是**编译期错误**；线以外**不许是 UB**。

这不是"不证就不查" —— 是"不在编译期查"。越界那条路走的是运行期:
字面量在编译期就拒，非字面量在运行期 **trap**（`docs/188` 的"宁拒勿猜"；
`docs/205` §2 那张对照表里"成本在哪一刻付"那一行说的是同一件事）。

## 4. 我不主张

1. **这不是规范。** 规范是 `docs/143`。这一页说的是**实现的边界**，不是语言的定义 ——
   两者的区别在下面第 3 条里体现得最清楚。
2. **这三条不是"一个所有权系统"**，是一组**界**。把它们读成"Loment 有 Rust 那套借用
   检查"是读错了；`docs/205` §3 把"Rust 的 NLL 级借用检查"列在**明确不抄**那七条里。
3. **§2 那四条是实现的事实，会随实现变。** 它们变了，这一页就该改。
   判断它有没有改的办法不是读这句话，是去读 `tools/lomentc.py` 里那两个函数。
4. **不主张它完备。** 这一页想把"能证 / 不证"写全，但它与实现之间没有一条判据钉着 ——
   这是它**今天**的状态。要它可信，下一步是给 §1 那三条各配一对夹具
   （一对必须被拒、一对必须被收），让边界由判据而不是由散文来定义。
