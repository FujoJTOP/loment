# 110 · W36 — 论文三立项：Potato（土豆）——Agent 的表示层（非世俗新语言）

> 状态: **立项（定位修订 2025-06）** · 定位: **不是新语言，是表示层**
> 一句话: **Potato 定义"Agent 如何看系统"——让大模型对任何训练密集的语言
> （Python/C/…）做快速结构识别与转写的目标表示；语法属于源语言，表示属于 Potato。**
> **它是整个项目唯一闭源的东西：规范公开、实现闭源（防"内核侵蚀"）。**

## 1. 为什么"世俗新语言"无意义（Potato 的否定前提）

- 大模型训练**几乎全面贴合 Python 等主流语言**——再创造一门新语言 = 零训练语料、
  零生成能力、纯自造障碍；
- 所以 Potato **不提供语法**。语法只属于源语言（Python/C/Rust——LLM 语料密集区，
  Agent 识别它们零成本）；
- Potato 提供的是**表示**：结构、语义、任务规格、产物 schema、能力声明——
  "那些语言"（文本/源码/二进制语义）被快速映射到 Potato 形式；
- 推论: **LLM 强项 = 把密集语言翻译成结构化表示；Potato = 那个目标表示本身**。
  没有"新语言无语料"问题: 语料在源语言, Potato 只消费结构。

## 2. Potato 与公理家族的关系（三部曲的缺角）

| 论文 | 问题 | Potato 的贡献 |
|---|---|---|
| 一 · FUAI | 什么被信（S1×S2×S3） | **hint 从自由文本 → Potato 形式对象**（可解析/可验证/可审计/可度量）——A1–A4 断言语义从字符串匹配升级为形式校验 |
| 二 · FUFORALL | 什么能跑（LEGO/BOX/出界） | **三支柱共用的载体语言**：语义转录产物（LEGO）、动词 schema（BOX）、出界声明（EXCLUDED）全是 Potato 形式 |
| 三 · Potato | **Agent 如何看一切** | 表示层公理化：外部智能体（模型/盒子）的输入输出形式 |

> 三部曲 = 信任（什么被信）→ 运行（什么能跑）→ **表示（Agent 如何看一切）**。
> Potato 不是独立第三篇, 是公理家族的**形式化载体**——前两篇的断言语义终于有了语法。

## 4. 闭源决策（唯一闭源层）及其张力解决

- **理由**：一旦开源, Potato 可被任何内核/框架直接内嵌（**"内核侵蚀"** = 被吸收为公共
  基础设施, 失去定义权）——保持闭源 = 保持"谁定义 Agent 如何看系统、谁拥有系统未来"。
  项目全部开源, Potato 是唯一战略保留地。
- **张力**：闭源与"证据先行"论文纪律冲突？——**不冲突, 用"规范/实现分离"解决**:
  论文三发表**规范 + 测量协议**（形式化定义、结构识别转换率/验证率观测、产物 schema
  合规率）, 实现闭源。先例: .NET（ECMA 规范 vs 厂商实现）、Java（规范 vs 厂商）。
- **诚实声明措辞（论文姿态）**：*Potato 的规范公开发表；参考实现保密——与
  FUAI 的 evidence-appendix 模式一致的是"证据公开", 不同的是"实现不公开",
  这是本项目的唯一刻意保密层。*

## 5. 论文三结构预览（证据先行）

1. **规范**：Potato 形式对象的类型系统/结构规则（正文主体, 形式化定义 + 定理级断言）；
2. **测量**：结构识别转换率——Python/C 源码 → Potato 形式（宿主 LLM + 低收益工具链,
   同 A/B 对照; 转换率/错误率/验证通过率 = 论文三主表, 参照论文一 B20 模式）；
3. **验证**：Potato 形式 → 内核断言语义（与 A1–A4 的 bind, 复用 m131/m149 类用例）;
4. **论文主句候选**：*Agent 的表示层公理: 系统的语义接口以形式化载体向外部智能体开放,
   而该载体（Potato）是该接口的唯一稳定语法*——"闭源"由规范/实现分离正当化。
