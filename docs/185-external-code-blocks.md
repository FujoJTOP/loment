# 185 · S1：外部代码块 + **字节保真**携带

> 上游：`docs/183` §8（多语言宿主语法，S1–S4）· `docs/184`（S4 `comefor`，同轴的第四步）。
> **本文件是设计 + 落点表 + 分步**，不是成果。按 `docs/176` §7.3 / `docs/182` §4 那条纪律，
> **它是动第一行代码之前的最后一步。**

## 0. 一句话

**让 Loment 当宿主：块里放别语言的正文，Loment 一个字节都不动它。**

## 1. 它长什么样

```rust
module myapp

command c                 // 主语言是 C（S2 用它决定谁来编）
foruse py                 // 这份文件还用 Python（S1 只用它**声明**，S2 才真去拉编译器）

let c {                   // ← 外部代码块：块里是 C 的正文
int add(int a, int b) {
    return a + b;
}
}

py {                      // ← 不带 `let` 的写法，等价
def sub(a, b):
    return a - b
}
```

**块里的东西对 Loment 是"一段字节"**，不是一个字符串字面量 —— 理由见 §2，那是这一节
唯一硬性的技术决定。

## 2. 为什么**不能**用字符串字面量装（`docs/183` §8.3，实测）

| | 事实 | 出处 |
|---|---|---|
| 转义表只有 4 条 | `n` `t` `"` `\` | `tools/lomc.py:69` |
| **未知转义静默退化** | `\0` → `"0"`、`\x41` → `"x41"` | 同上 |
| **没有非 UTF-8 通道** | 源按 UTF-8 文本读 | `read_text(encoding="utf-8")` |

第一条与第二条合起来就是**静默改内容** —— 正是本仓反复要消灭的东西：写 `"\0"` 得到两个
字符，编译器一声不吭。所以正文必须走**新词法模式**：`{` 到配对的 `}` 之间
**按原始字节**收成一个 token，不经过转义表。

## 3. 两种写法与消歧（`docs/183` §8.5：用户已定，都要、且等价）

| 写法 | 什么时候认 | 为什么没有歧义 |
|---|---|---|
| `let IDENT {` | **总认** | 今天 `let` 只接 `IDENT :` / `IDENT =`。`let x { … }` 现在**解析不过**，所以这个产生式是新加的，不撞任何既有语法 |
| `IDENT {` | 只在 `IDENT` 是**本文件声明过的语言名**时认 | 撞的是 `struct S {` / `fn f() -> u32 {` —— 那两个的 `{` 前面也是标识符。靠"必须是语言名"把那两个排除掉 |

**语言名从哪来**：`command <语言>` / `foruse <语言>` 声明，**必须写在块前面**
（与 `set choose` 必须先定义、`comefor` 必须先定义同一条纪律）。

⇒ **S1 要认 `command` / `foruse` 这两个声明**（只认声明、只用来消歧），
**真去拉编译器是 S2**。这条分界写在这里，免得 S2 的人以为 S1 已经接上了。

## 4. 三个必须钉死的形状

### 4.1 token：kind = **5**（raw）

20 字节记录不变：`+0 kind(=5) +4 off +8 len +12 line +16 col`。
`off`/`len` 圈的是 `{` 与 `}` **之间**的原始字节（**不含**两侧花括号，也**不含**
花括号前后的空白 —— 正文里有什么就是什么）。

**自举侧 `lexer.lomt` 头的 kind 表要跟着加一行**（`5=raw`）—— 两个实现的 kind 编码
必须同表，这是 `loment_p8_test` 的 token 流对照能成立的前提。

### 4.2 `{` 配对是**朴素计数** —— 这是已知边界

从开 `{` 起数 `{` / `}` 两个字节，计数归零就收尾。**不认识字符串、不认识注释。**

⇒ `printf("}");` 这样的正文会**提前收尾**。**如实记**，不粉饰：

- 为什么不做聪明的：聪明的要**懂目标语言的词法**，而这一节的全部意义就是
  "Loment 不懂那个语言"。懂一半比不懂更危险 —— 它会**猜错边界**且看不出来。
- 为什么朴素是可接受的：C/Python 的正文里 `}` 出现在字符串里是少数；
  真遇上了，症状是**一处编译错**（剩下的正文变成了 Loment 代码），指得出位置。
- 判据会**钉一条**把"提前收尾"变成**看得见的行为**（§6 的反例），不是让它成为暗礁。

### 4.3 正文的**位置**从哪来

新 token 的 `line`/`col` 取正文**第一个字节**的位置（空块取 `}` 的位置）。
正文里逐行的行号 Loment **不记** —— 报错指到块的起点。这是 §5 的代价之一。

## 5. 落点表（`docs/176` §7.3：找不到落点的那条就是真实代价）

| 规则 | 参考实现 | 自举 |
|---|---|---|
| **raw 模式** | `lomc.lex`（新分支） | `loment/selfhost/lexer.lomt`（新分支） |
| **`let IDENT {` 的判定** | 词法器**回看两个 token**（刚发的 `{` 的前面是 `IDENT`、再前面是 `let`） | 同 |
| **`IDENT {` 的判定** | 词法器维护一张**已声明语言名**表 | 同 |
| **新 AST 节点** | `ExtBlock(lang, raw)` | **无 AST** —— 自举的 checker/codegen 在 token 上工作，raw token 天然过得去 |
| **进 Potato** | 新字段（**v5**，见 §7 ①） | 自举**无** potato 发射器（既有边界） |
| **codegen** | 正文**原样**写进产物的一个段 | 同 |

**自举侧比参考侧少一件**：它没有 AST，所以"新节点"这一格是空的。这与 `docs/184` §6
那条对称 —— 两边只有 token 是共有的。

## 7. 墙与代价（如实记）

**① Potato 要升 v5，不是 v4。** `docs/183` §8.3 原写"升 v4"，而 **v4 已被 `comefor`
的 `dialects` 用掉**（`docs/184` §7 ②，同日落地）。本仓规矩是**一个必填字段一次升版**
（v2 = `mode`、v3 = `switches`、v4 = `dialects`），所以外部代码正文 = **v5**。
塞进 v4 的话，"删掉字段校验器必须红"那条判据就没法对两个字段各来一次。

**② 朴素配对的边界**（§4.2）。**这条是这一节最贵的地方** —— 它不是"以后再修"，
是"要么懂目标语言、要么接受猜错边界"，而这一节的立意就是不学那个语言。

**③ 正文的位置只到块首**（§4.3）。目标语言里报的错**指不回** Loment 的对应行 ——
要指得回，得让目标编译器吐行映射，那是**另一件事**（`docs/179` 的多语法前端那一侧）。

**④ `command` / `foruse` 在 S1 只是声明。** 不拉编译器、不选运行期 ——
那是 S2/S3。S1 认它们**只为了让不带 `let` 的写法没有歧义**。

## 8. 不做什么（边界）

- **不做"懂目标语言"的配对** —— §4.2，那是这一节的反面。
- **不给 Potato 塞通用 `body`** —— `docs/183` §8.6 明写：先只加"外部代码正文"这一种。
- **不在 S1 里拉编译器** —— S2。
- **不做行映射** —— §7 ③。

### 9.1 自举侧还差什么（下一步的清单，不是估计）

自举侧的第一遍扫描是**逐 token 跳过**式的，所以 `command` / `foruse` / raw 本身**不会**
让它崩 —— 崩的是别处（实测 `E2 @9 line 21: py`：`py` 被当成一次**标识符使用**去查符号表）。
所以要做的是：在顶层认出这三样**并跳过**（`command|foruse IDENT` 两个 token / `IDENT raw`
/ `let IDENT raw`），而不是让它们掉进"表达式/语句"那条路。

**与 `comefor` 的镜像不同**：那边要**跑**宏体（所以有 `ct_call_toks`、语境块、四个内建）；
这边**什么都不用做** —— 正文是死的，自举侧只要"不报错地跳过去"。**这一格便宜得多。**

### 9.3 顺手撞出来的：字符串里的裸换行（**语料没覆盖过**）

落 S1.2/S1.3 收尾时，`driver.lomt` 里一句 `fail("…\n")` 被 heredoc 腐蚀成了**字面换行**。
两个词法器都默默收下、种子照样一致、门禁整道绿 —— 因为**语料里从来没有一份源在字符串
字面量里带换行**。又一次是"形状不存在，判据就测不到它"。

**第一处分歧不在词法器里，在对照夹具**：`loment_p8_test._python_tokens` 当时从
`(line, col)` **反推**字节偏移，而它建的行首表把字符串里那个换行也算了一行 —— 于是从
那个 token 起两边偏移整体差 4 字节，**越往后差得越多**。词法器两侧的 `(kind, off, len,
line, col)` **本来就是逐 token 全等的**，错的一直是重建那一步。夹具现在直接用
`off`/`len`（词法器给的是**字符**下标/长度，Loment 那侧报字节，那里做一次换算）。

**第二件（值）**：`"a\nb"`（真换行）的 IR 是 `c"\61\0A\62"` —— **十六进制转义**，
不是把裸字节写进 LLVM 字符串常量。这一条本来就是对的，现在有语料钉住。

**第三件是缺口，没修**：Rust 不许字符串里有裸换行（`"abc<换行>def"` 是**两个**错误：
未闭合 + 后面那半截），而 Loment 只在"到尾都没找到闭引号"时报 `未闭合的字符串` ——
中间有换行、后面又有引号的会被当成一条**跨行字符串**收下。于是"Loment 是 Rust 的严格
子集"这条性质上有个洞。**要堵是语言面改动**（两个词法器各一条 + 一条反例 + 双倍工），
不在 S1 这条线上，所以这里只记着，`loment/examples/multiline_str.lomt` 把那形状钉住。
